# 专注模式设计

## Concept & Vision

玻璃态番茄钟与待办系统的深度整合。选择一个待办事项，进入25分钟专注计时，完成后可选择标记为完成或继续。专注期间界面呈现沉浸式暗色，减少干扰，营造专注氛围。

## Design Language

- 沉浸式暗色背景（类似 QuickAddPanel 的模糊遮罩）
- 中心大号计时器显示，视觉焦点
- 玻璃态卡片承载任务信息
- 颜色：工作阶段使用强调色，休息阶段使用绿色调
- 图标风格：简洁线性 SVG

## Features & Interactions

### 入口
- 在 TodoItem 上添加专注按钮（番茄图标）
- 点击后弹出"选择专注任务"对话框
- 选择任务后进入专注模式

### 专注模式
- 默认25分钟工作 + 5分钟休息
- 计时器居中大号显示（MM:SS）
- 显示当前任务标题
- 三个操作按钮：暂停/继续、结束专注
- 工作完成时发送系统通知，询问是否标记任务完成
- 休息结束通知后可开始新一轮或退出

### 状态
- `idle` - 未开始
- `working` - 专注中（25分钟）
- `paused` - 暂停
- `break` - 休息中（5分钟）
- `completed` - 完成

## Component Inventory

### FocusModal
- 全屏遮罩 + 玻璃态卡片
- 包含 Timer、TaskInfo、Controls

### Timer
- 大号数字显示剩余时间
- 圆形进度环（可选）
- 状态对应颜色变化

### Controls
- 暂停/继续按钮
- 结束专注按钮
- 跳过休息按钮（休息阶段）

## Technical Approach

- 新增 `src/components/FocusModal.tsx`
- 新增 `src/store/focus.ts` 或在 store 中添加 focus 状态
- 使用 `setInterval` 计时，精度到秒
- 使用 `Notification` API 发送系统通知
- 关闭时清理定时器，避免内存泄漏
